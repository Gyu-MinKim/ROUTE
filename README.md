# ROUTE

시간, 교통비, 체력을 관리하며 목적지까지 이동하는 웹 경로 퍼즐 게임입니다. 도보·버스·지하철을 조합하고, 플레이한 경로를 서버가 계산한 기준 경로와 비교할 수 있습니다.

## 실행

Node.js 18 이상과 npm이 필요합니다.

```bash
npm ci
npm start
```

브라우저에서 [localhost:3000](http://localhost:3000)을 엽니다. `PORT` 환경 변수로 포트를 변경할 수 있으며, 별도 API 키나 데이터베이스 설정은 필요하지 않습니다.

```bash
npm test
```

테스트는 DOM 환경과 실제 Express 핸들러를 연결해 화면 흐름, 이동, 재도전, 캠페인 연동을 확인합니다. 실제 브라우저의 화면 배치와 터치 조작은 별도로 확인해야 합니다.

## 주요 기능

- 15개 레벨, 상황별 캠페인 3종, 일주일 등교, 라운드형 무한 모드.
- 시간·교통비·체력 제약과 환승 요금 규칙.
- 교통 지연·운행 중단 사건, 선택 경유 미션과 결과 이야기.
- 도착·추가 목표·자원 절약을 평가하는 레벨별 별점.
- 같은 지도 재도전, 내 경로와 기준 경로 비교, 경로 재생.
- 모바일 화면, 키보드 선택, 다크 모드, 애니메이션 줄이기.

인접 역을 선택하고 수단 카드를 누르면 바로 이동합니다. 수단 단축키는 `1`·`2`·`3`이며, 이동은 되돌릴 수 없습니다. 생각하는 동안에는 게임 시간이 줄어들지 않습니다.

## 기술 구성

| 구분 | 사용 기술 |
| --- | --- |
| 화면 | HTML, CSS, Vanilla JavaScript, SVG |
| 서버·통신 | Node.js, Express 5, Fetch API, JSON REST API |
| 경로 탐색 | 최소 힙을 이용한 다익스트라 기반 상태 확장 탐색 |
| 저장 | 브라우저 localStorage·sessionStorage, 서버 메모리, JSON 파일 |
| 테스트 | LinkeDOM, Node.js assert |

별도 프런트엔드 빌드 과정은 없습니다.

## 파일 구조

```text
server.js              # API, 세션 관리, 이동·결과 판정
lib/engine.js          # 지도 생성, 이동 규칙, 경로 탐색
routes.json            # 교통수단, 레벨, 캠페인 설정
public/                # 화면 HTML, CSS, 클라이언트 JavaScript
tests/                 # 화면·API 연동 테스트
docs/                  # 발표자 가이드, 기술·데이터 구조 설명
package.json           # 실행 명령과 의존성 정의
package-lock.json      # 설치 의존성 버전 고정
data/                  # 실행 중 생성되는 결과 기록 (Git 제외)
```

## 데이터와 진행 저장

역 이름과 게임 규칙을 이용해 게임용 지도를 생성합니다. 실제 지도나 실시간 교통 API는 사용하지 않습니다.

설정·레벨별 최고 별점은 브라우저에 저장합니다. 진행 중 라운드와 일주일 캠페인은 서버 메모리에 있으며 서버 재시작 시 사라집니다. 현재 화면의 이어 하기는 같은 탭에서만 지원하며 새로고침 후 진행 중 판을 복원하지 않습니다. 서버 결과 기록은 `data/game_history.json`에 최근 최대 500건을 보관합니다.
