# ROUTE 경로 플래너 (MVP)
실행: `npm ci && npm start` → http://localhost:3000 (Node.js 18 이상)

- 게임 루프: 나종민_게임루프(최상위) → 설정/튜토리얼 스킵 → 랜덤 미션(목적지 줌인) → 노드 클릭+수단 선택 → 결과/등급 → 경로 비교 → 실패 시 최적해 재생 → 라운드 난이도 상승, 캠페인 3종
- 서버(Express): routes.json(수단/역/캠페인), POST /api/simulate/start|step|giveup, GET /api/routes|history, data/game_history.json(없어도 동작)
- 서버 규칙 5: 동적 시간 계산 / 날씨(비)·파업 보정(결정적) / 자원 차감 / 시간·자원 부족 판정 / 입력값 검증
- 유저 정보 없음: 설정·플레이 횟수는 localStorage/sessionStorage, 초기화돼도 플레이 가능

## 레벨 모드 (추가)
- 시작 화면 "🎯 레벨 선택": Level 1~15, 이전 레벨 클리어 시 해금, 별 3개는 독립 목표(★ 제한 시간 내 도착 / ★ 목표 시간 이내 / ★ 교통비 또는 체력 절약 — 최적 경로 기준으로 산출되어 항상 달성 가능). 진행은 localStorage(`route.progress`).
- 레벨 선택 시 "상황 카드"(날씨·이동 타입·스토리) 표시 후 시작.
- ❤️ 체력: 도보 > 버스 > 지하철 순으로 소모. 이동 타입(체력 좋음/보통/나쁨/발목 부상)에 따라 최대 체력·도보 소모가 다름. 최적 경로도 체력 제약을 만족하도록 서버가 계산.
- 레벨 정의: `routes.json`의 `levels`, `personas`. API: `POST /api/simulate/start {mode:'level', levelId}`.
- 보류: 카카오맵 실제 노선, 일러스트 그래픽, 성별 요소(미구현).
- 같은 지도 재도전: 라운드 종료 후 `POST /api/simulate/retry {sessionId}` → 맵·조건은 그대로, 이동 상태만 초기화(모든 모드).

## 사건 · 심부름 · 일주일 등교 (추가)
- 예고형 사건(`levels[].event`): 출발 후 일정 시각부터 특정 수단이 느려지거나 중단(버스 지연/소나기/지하철 중단). 시각은 미리 공개되고, "출발 시각" 기준으로 견적·서버 판정·최적 경로가 같은 규칙(`engine.timeAt`)을 쓴다. 레벨 5·7·13·15.
- 심부름(`levels[].errand`): 지도에 표시된 역을 경유하는 선택 목표. 해당 레벨의 ★2는 "심부름 완료"이며, 최적 경로는 경유 포함으로 계산. 도착 메시지가 선택에 따라 달라진다. 레벨 6·10·14.
- 일주일 등교(`week`): 월~금 5일. 남긴 교통비의 절반(최대 ₩1,500)을 저금 → 수요일 우산 구매, 금요일 교통비에 보탬. 화요일에 민수를 도우면 목요일 버스 지연 시각을 알려 준다(안 도우면 시각 미상). 지각하면 다음 날 체력 -15. 지각해도 다음 날로 진행.
  API: `POST /api/week/start`, `POST /api/week/next {weekId}`, `POST /api/simulate/start {mode:'week', weekId, choice}`. 진행은 서버 메모리에만 있어 재시작 시 초기화.

## 조작 (추가)
- 구간 위 숫자는 수단별 소요 시간(분). 역을 누르면 수단 카드가 뜨고(넓은 화면은 역 옆, 좁은 화면은 하단), 카드를 누르면 바로 이동한다. 단축키 1·2·3. 이동은 되돌릴 수 없다.

## 기술 구성 및 검증
- 화면: HTML5, CSS3, Vanilla JavaScript, SVG. 별도 프런트엔드 빌드 도구 없이 제공한다.
- 서버: Node.js, Express 5, JSON REST API. 서버가 이동 비용·체력·성공 여부를 판정한다.
- 경로 계산: 최소 힙을 사용하는 다익스트라 기반 상태 확장 탐색. 역·사용 자금·환승 잔여 시간·체력·경유 여부를 함께 고려한다. 체력 탐색은 5 단위로 보수적으로 양자화한다.
- 데이터: `routes.json`에 게임 규칙, 브라우저 localStorage에 설정·레벨 진행, 서버 메모리에 진행 중 세션, `data/game_history.json`에 최근 최대 500건의 결과를 저장한다. 별도 데이터베이스는 사용하지 않는다.
- 테스트: `npm test`. 테스트 전용 DOM 환경과 실제 Express 핸들러로 화면 흐름·이동·재도전·캠페인 연동을 확인한다. 실제 브라우저의 배치·터치 조작은 별도 확인이 필요하다.
- `PORT` 환경 변수로 서버 포트를 바꿀 수 있다. 실제 교통 API나 지도 API는 사용하지 않으며, 역과 구간은 게임용으로 생성한다.
