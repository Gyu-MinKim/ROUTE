# ROUTE 발표 피드백

발표 후 받은 의견을 주제별로 정리했다. 아래 제안은 구현이 확정된 사항이 아니다.

| 주제 | 반응과 제안 |
| --- | --- |
| 게임의 정체성 | 광운대 학생에게 익숙한 1호선 환승과 지각 상황을 퍼즐로 바꾼 점이 좋았다. 다만 실제 등굣길에 쓰는 서비스라면 플레이에 시간이 더 든다. 길 안내와 게임 중 무엇이 목적인지 첫 화면과 발표에서 분명히 해 달라는 의견이 있었다. |
| 경로 선택 | 시간·교통비·체력을 함께 고려하고 비, 지하철 중단, 캐릭터 상태에 따라 경로가 달라지는 점이 흥미로웠다. 기준 경로가 무엇을 우선하는지 표시하고, 제한 시간 안에 도착하는 최저 비용 경로와 가장 빠른 경로를 따로 비교하고 싶다는 의견이 있었다. |
| 실패와 재도전 | 내 경로를 비교하고 실패 원인을 확인하는 기능은 좋았다. 첫 실패에 전체 정답이 보이면 다음 판은 따라가기가 된다. 처음에는 개선할 구간만 짚고, 같은 지도에서 여러 번 실패하면 전체 경로를 열어 달라는 제안이 있었다. |
| 체력의 의미 | ‘85/85’와 수단별 차감량만으로는 버스가 지하철보다 피곤한 이유를 알기 어렵다. 이동 전에 소모량과 그 근거를 함께 보고 싶다는 의견이었다. |
| 난이도와 반복 | 같은 맵의 하드 모드, 매판 달라지는 조건, 돌발 사건과 새로운 기능을 원했다. LLM으로 변수를 만드는 아이디어도 나왔다. 다크 모드는 긍정적인 반응을 얻었다. |
| 기록과 공유 | 개인 기록에 재도전하는 모드와 랭킹을 제안했다. 인스타그램이나 카카오톡으로 결과를 자랑하고 친구가 게임에 들어올 수 있으면 좋겠다는 의견이었다. |
| 조작 실수 | 수단 선택 즉시 이동해 한 번의 오입력이 판을 끝낼 수 있다. 비용이나 시간 손해를 감수하고 판당 한 번 되돌리는 방식을 제안했다. |
| 역 이름 | 서울역에 ‘역’이 한 번 더 붙어 ‘서울역역’처럼 보인다는 제보가 있었다. |
